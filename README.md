One line, at most 200 characters: the funniest one-line review of my own Monday. A judge model compares the lines two at a time and the funniest wins.

## The review

> One star: Monday showed up late, froze during standup, and then asked me to rate the experience.

96 characters: Monday reviewed like a broken app — it arrived late, froze in the morning standup, and still had the nerve to ask for a rating.

## Run it

```sh
node main.ts
```

`main.ts` writes the review to `/output/entry.txt` (96 bytes, no trailing newline) and refuses loudly if the text ever leaves the one-line, 1–200-character, exactly-one-sentence gate.
